# Bank-Debit-and-Credit-Analysis (Interactive-Dashboard-Creation-Using-PowerBi)
Bank Debit &amp; Credit Analysis Dashboard 📊 An interactive Power BI dashboard tracking 127M+ in transaction volumes. It monitors cash flows, account activity ratios, and high-risk flags across banking branches. Features dynamic monthly trends, waterfall charts for transaction growth rates, and slice-and-dice data filtering by branch, risk, or month.
